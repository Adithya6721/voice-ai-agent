# VAD Models

Place Voice Activity Detection model files here.

## Silero VAD

Silero VAD is automatically downloaded on first run via the `silero-vad` package
or `torch.hub`. No manual download required.

- Package: `pip install silero-vad`
- GitHub: https://github.com/snakers4/silero-vad
- HuggingFace: https://huggingface.co/snakers4/silero-vad

The ONNX model is cached at:
- Windows: `C:\Users\<user>\.cache\torch\hub\`
- Linux/Mac: `~/.cache/torch/hub/`
